## 🚀 QUICK START (New User)

### 1. Activate environment

```bash
cd /home/tp/projects/active/hermes
source .venv/bin/activate
```

### 2. First run auto-creates config

```bash
hermes ask "check disk on garage-core"
# Automatically creates /home/tp/.hermes_data/ with defaults
```

### 3. Customize your config

```bash
nano ~/.hermes_data/config.json

# Key settings to verify:
{
  "ollama_url": "http://192.168.0.129:11434",  # garage-core Ollama
  "ops_model": "gemma4:e4b",                    # primary LLM
  "whitelisted_hosts": ["garage-core"],         # SSH security
  "ssh_key_path": "~/.ssh/id_ed25519",          # SSH auth
  "api_token": "your-secret-token-here"         # HTTP auth
}
```

## 🔄 MIGRATION: `.hermes/` → `.hermes_data/`

### Why rename?
- **Clear:** `.hermes_data/` obviously means "data", not source code
- **Prevents confusion:** No one thinks it's the project itself
- **Better docs:** Easier to write "config is in `.hermes_data/`"

### Migration steps

**Step 1: Backup**
```bash
cp -r ~/.hermes ~/.hermes.backup-$(date +%s)
```

**Step 2: Rename**
```bash
mv ~/.hermes ~/.hermes_data
```

**Step 3: Test**
```bash
cd /home/tp/projects/active/hermes
source .venv/bin/activate
hermes ask "check disk on garage-core"
# Should work with config from ~/.hermes_data/config.json
```

**Step 4: Verify**
```bash
# Check config was read
ls -la ~/.hermes_data/config.json

# Check database still has history
sqlite3 ~/.hermes_data/hermes.db "SELECT COUNT(*) FROM tasks;"

# Check audit logs
ls ~/.hermes_data/audit/
```

**Step 5: (Optional) Create symlink for old scripts**
```bash
ln -s ~/.hermes_data ~/.hermes
```

## 🔧 COMMON TASKS

### View current config
```bash
cat ~/.hermes_data/config.json | jq .
```

### Check task history
```bash
sqlite3 ~/.hermes_data/hermes.db \
  "SELECT id, query, status, created_at FROM tasks ORDER BY created_at DESC LIMIT 10;"
```

### View audit logs
```bash
tail -f ~/.hermes_data/audit/audit-$(date +%Y-%m-%d).jsonl
```

### Manual backup
```bash
cp -r ~/.hermes_data ~/.hermes_data.backup-manual-$(date +%s)
```

## 🐛 TROUBLESHOOTING

### "Config file not found"
```bash
# Create manually
mkdir -p ~/.hermes_data
cat > ~/.hermes_data/config.json << 'EOF'
{
  "ollama_url": "http://192.168.0.129:11434",
  "ops_model": "gemma4:e4b",
  "whitelisted_hosts": ["garage-core"],
  "ssh_key_path": "~/.ssh/id_ed25519",
  "api_token": "dev-token-insecure"
}
EOF
```

### "Database is locked"
```bash
pkill -TERM -f "hermes"
sleep 2
hermes ask "check disk"
```

### "SSH key permission denied"
```bash
chmod 600 ~/.ssh/id_ed25519
ssh -i ~/.ssh/id_ed25519 garage-core "uptime"
```
